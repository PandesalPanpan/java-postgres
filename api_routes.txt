================================================================================
STUDENT GRADE MANAGEMENT API - TEST ROUTES
================================================================================

Base URL: http://localhost:8080
Content-Type: application/json

================================================================================
1. CREATE STUDENT
================================================================================
POST /students

Request Body:
{
  "full_name": "Juan Dela Cruz"
}

Example cURL (Windows - Single Line):
curl -X POST http://localhost:8080/api/students -H "Content-Type: application/json" -d "{\"full_name\": \"Juan Dela Cruz\"}"

PowerShell (Multi-line with backticks):
curl -X POST http://localhost:8080/api/students `
  -H "Content-Type: application/json" `
  -d "{\"full_name\": \"Juan Dela Cruz\"}"

CMD (Multi-line with ^):
curl -X POST http://localhost:8080/api/students ^
  -H "Content-Type: application/json" ^
  -d "{\"full_name\": \"Juan Dela Cruz\"}"

Expected Response (201 Created):
{
  "id": 1,
  "fullName": "Juan Dela Cruz"
}

Note: Save the "id" (numeric) from the response for use in subsequent requests.

================================================================================
2. GET STUDENT
================================================================================
GET /students/{studentId}

Example cURL:
curl -X GET http://localhost:8080/students/1

Expected Response (200 OK):
{
  "id": 1,
  "fullName": "Juan Dela Cruz"
}

================================================================================
3. ADD SUBJECT GRADE
================================================================================
POST /api/students/{studentId}/subjects

Request Body:
{
  "subject_name": "Mathematics",
  "subject_code": "MATH101",
  "semester": "1st",
  "school_year": "2025-2026",
  "teacher_id": 1,
  "grade": 95
}

Note: teacher_id and grade are optional. If grade is null, the subject grade is ungraded.

Example cURL (Windows - Single Line):
curl -X POST http://localhost:8080/api/students/1/subjects -H "Content-Type: application/json" -d "{\"subject_name\": \"Mathematics\", \"subject_code\": \"MATH101\", \"semester\": \"1st\", \"school_year\": \"2025-2026\", \"teacher_id\": 1, \"grade\": 95}"

PowerShell (Multi-line):
curl -X POST http://localhost:8080/api/students/1/subjects `
  -H "Content-Type: application/json" `
  -d "{\"subject_name\": \"Mathematics\", \"subject_code\": \"MATH101\", \"semester\": \"1st\", \"school_year\": \"2025-2026\", \"teacher_id\": 1, \"grade\": 95}"

Expected Response (201 Created):
{
  "subjectName": "Mathematics",
  "subjectCode": "MATH101",
  "semester": "1st",
  "schoolYear": "2025-2026",
  "grade": 95,
  "teacherName": "Dr. Maria Garcia"
}

Example: Add subject without grade (ungraded):
curl -X POST http://localhost:8080/api/students/1/subjects -H "Content-Type: application/json" -d "{\"subject_name\": \"Science\", \"subject_code\": \"SCI101\", \"semester\": \"1st\", \"school_year\": \"2025-2026\", \"teacher_id\": 3}"

Note: You can add multiple subjects for the same student.

Additional Examples:

Science Subject with Teacher (Single Line):
curl -X POST http://localhost:8080/api/students/1/subjects -H "Content-Type: application/json" -d "{\"subject_name\": \"Science\", \"subject_code\": \"SCI101\", \"semester\": \"1st\", \"school_year\": \"2025-2026\", \"teacher_id\": 3, \"grade\": 88}"

English Subject with Teacher (Single Line):
curl -X POST http://localhost:8080/api/students/1/subjects -H "Content-Type: application/json" -d "{\"subject_name\": \"English\", \"subject_code\": \"ENG101\", \"semester\": \"1st\", \"school_year\": \"2025-2026\", \"teacher_id\": 2, \"grade\": 92}"

================================================================================
5. UPDATE GRADE
================================================================================
PATCH /subjects/{subjectGradeId}

Request Body:
{
  "grade": 97
}

Example cURL (Windows - Single Line):
curl -X PATCH http://localhost:8080/api/subjects/1 -H "Content-Type: application/json" -d "{\"grade\": 97}"

PowerShell (Multi-line):
curl -X PATCH http://localhost:8080/api/subjects/1 `
  -H "Content-Type: application/json" `
  -d "{\"grade\": 97}"

Expected Response (200 OK):
{
  "subjectName": "Mathematics",
  "subjectCode": "MATH101",
  "semester": "1st",
  "schoolYear": "2025-2026",
  "grade": 97,
  "teacherName": "Dr. Maria Garcia"
}

Note: Use the subject grade ID from the grade sheet response or from the add subject response.
Note: grade can be set to null to mark as ungraded, or updated with a valid grade value.

================================================================================
TESTING WORKFLOW EXAMPLE
================================================================================

Step 1: Create a student
POST /api/students
{
  "full_name": "Maria Santos"
}
Response: Save the student ID (e.g., 1)

Step 2: Create teachers (optional, if not already in database)
POST /api/teachers
{
  "full_name": "Dr. Maria Garcia"
}
Response: Save the teacher ID (e.g., 1)

Step 3: Add multiple subjects (with teachers and grades)
POST /api/students/1/subjects
{
  "subject_name": "Mathematics",
  "subject_code": "MATH101",
  "semester": "1st",
  "school_year": "2025-2026",
  "teacher_id": 1,
  "grade": 95
}

POST /students/1/subjects
{
  "subject_name": "Science",
  "subject_code": "SCI101",
  "semester": "1st",
  "school_year": "2025-2026",
  "teacher_id": 3
}

Note: Second subject has no grade - it's ungraded and waiting for teacher to grade.

Step 4: View the grade sheet
GET /api/students/1/grades

Step 5: Update a grade (use subject grade ID from step 4, e.g., 1)
PATCH /api/subjects/1
{
  "grade": 97
}

Or set grade to NULL to mark as ungraded:
PATCH /api/subjects/2
{
  "grade": null
}

Step 6: View updated grade sheet
GET /api/students/1/grades

Step 7: Delete a subject grade
DELETE /api/subjects/1

Step 8: Delete the student (this will delete all remaining subject grades)
DELETE /api/students/1

Step 9: Delete a teacher (this will set teacher_id to NULL for associated subject grades)
DELETE /api/teachers/1

================================================================================
WINDOWS COMMAND LINE NOTES
================================================================================

1. Single-line commands work in both CMD and PowerShell
2. For multi-line in PowerShell, use backticks (`) at the end of each line
3. For multi-line in CMD, use caret (^) at the end of each line
4. JSON strings in Windows: Use double quotes for outer string, escaped quotes for inner JSON
5. Example: -d "{\"key\": \"value\"}" works in Windows

================================================================================
NOTES
================================================================================

1. Replace IDs in examples with actual numeric IDs from your responses
2. All IDs are numeric (Long type, e.g., 1, 2, 3, etc.)
3. Grade values are numeric (can be decimal, e.g., 95.5) or null (ungraded)
4. Teacher ID is optional when adding subject grades
5. When grade is null, the subject grade exists but is ungraded (waiting for teacher to grade)
6. All endpoints return JSON except DELETE operations (204 No Content)
7. Make sure your Spring Boot application is running on port 8080
8. If using a different port, update the base URL accordingly
9. All cURL commands above are Windows-compatible (single-line format)
10. All API endpoints are prefixed with /api (e.g., /api/students, /api/teachers, /api/subjects)
